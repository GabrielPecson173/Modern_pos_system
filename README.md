# Aqua Crystal POS

## Structure
- `frontend/`: React + Vite app (Orders, Laundry pages, mock data).
- `backend/`: Django API (to be completed).

## Development
1. Backend (later): `cd backend && python manage.py runserver` (http://localhost:8000)
2. Frontend: `cd frontend && npm run dev` (http://localhost:5173)
   - APIs proxy to backend :8000 (mocks if no backend).
